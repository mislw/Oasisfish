# Agent Note: 生图提示词优化

Status: implemented

[English](2026-09-07-image-prompt-refinement.md) | 中文

## 问题

生图能力会接受任意 prompt 字符串，因此 Agent 可能把用户的简短描述直接转发给已配置的生图模型。即使对话模型理解需求，提供方收到的信息仍可能缺少构图、镜头、光线、材质、空间关系、完成质感和常见缺陷约束。

## 决策

`image_generate` Schema 要求当前对话模型在调用已配置的生图模型前，把用户需求优化为一条连贯、可直接生成的英文共同 prompt，并提供四条简短候选差异。优化过程保留用户明确指定的主体、数量、可见文字、宽高比、风格、排除项和参考图约束，只增加与当前任务相关的视觉细节。该过程发生在现有对话模型轮次内；Harness 不会在后台额外发起第二次模型请求，也不会改变 Session 已选择的对话模型。

Oasisfish 内置从 YouMind OpenLab revision `6ef324c0aaf3bae6605e21be08f510a7a3fa0cfb` 适配的离线 `ai-image-prompts` Skill。该 Skill 为游戏资产、UI 图片、mockup、海报、产品、肖像、插画、信息图和参考图编辑提供简洁的视觉配方，其来源记录和 MIT 许可证随安装包提供。内置版本不会自更新、下载示例、联系上游服务，也不会在模型回复中附加推广署名。

专用 `game-image` 和 `game-ui` preset 会在生图前通过显式的本地 `skill_search` 检索配方。专注的 `game-image` 路径只加载 `ai-image-prompts` 并只检索一次，不加载或检索 `oasis-wiki`。纯生图入口只打开空白 `game-image` 会话，不提交启动消息，也不显示阶段；用户输入需求后，Agent 静默完成 Skill 加载、配方检索和 prompt 优化并直接生图。标准 preset 会在目录中看到该 Skill，在桌面本地提供方可用时拥有相同的检索工具，并从 `image_generate` Schema 获得提示词优化要求。“模型与中转站”页面会从对话默认选择器中排除明确的 `gpt-image-*` 路由，避免把提示词优化请求发到纯生图 Chat Completions 路由。生图使用单独配置的主路由，并在主路由非取消失败后尝试一次可选备用路由。

每次工具调用会用共同 prompt 和一条候选差异发起四个独立候选。每个候选分别执行主路由到备用路由的尝试顺序。结果按请求顺序保留成功候选，并以“已生成 N 个方案，请选择。”结束本轮；某些候选失败不会丢弃其他结果。桌面端以两列网格展示候选，支持原图预览、下载，以及只把所选图片放入当前输入框草稿的选择操作。

## 验证

包测试断言生成的工具 Schema 包含提示词优化与四候选要求，并覆盖独立备用尝试、部分成功和持久结果图片块。preset 组装测试断言专用生图工作流暴露 `skill_search`、不暴露阶段工具、携带静默优化指令、只检索一次 `ai-image-prompts`，并且不检索 `oasis-wiki`。浏览器端到端测试断言点击纯生图不会提交启动消息或显示阶段。桌面资源和 staging 清单测试要求 Skill、视觉配方、来源记录与许可证齐全。无密钥 assembled snapshot 会执行四次确定性提供方请求，记录四个图片块，并且不再发起对话模型收尾请求。

## 考虑过的替代方案

**额外发起一次专门改写提示词的 GPT 请求。** 不采用，因为当前对话模型可以在现有轮次内生成工具参数，额外请求只会增加隐藏延迟、费用、失败处理和另一项模型可见操作。

**让生图跟随对话默认路由。** 不采用，因为提示词优化和图片渲染需要不同的提供方端点。对话模型负责生成工具参数；生图服务持有自己的主路由和可选备用路由。

**原样内置上游 Skill。** 不采用，因为运行时更新、示例下载和回复推广不适合自包含桌面工作流。固定 revision 的离线适配保留有用的视觉指导及其许可证，同时移除外部副作用。

**硬编码一套通用提示词模板。** 不采用，因为图标、肖像、UI 背景、产品图和参考图编辑需要不同的构图与缺陷控制。本地配方允许对话模型选择相容的细节，而不是给每条 prompt 堆叠相同的形容词。

## 后果

- 简短生图需求会以信息更充分、针对任务的英文 prompt 进入已配置的生图模型。
- 产品有一个主生图模型和一个可选备用模型；提示词优化不会补齐提供方不支持的功能，也不保证渲染质量。
- 专用生图工作流会在生成前执行本地检索，实际对话与生图请求继续使用原有凭据和网络要求。
- 用户要求出现在图片中的文字保持原语言，即使外围生图 prompt 使用英文。
- 一次生图请求现在最多消耗四次提供方生成；主路由失败时，每个候选还可能增加一次备用路由尝试。
