# Agent Note: 生图提示词优化

Status: implemented

[English](2026-09-07-image-prompt-refinement.md) | 中文

## 问题

生图能力会接受任意 prompt 字符串，因此 Agent 可能把用户的简短描述直接转发给已配置的生图模型。即使对话模型理解需求，提供方收到的信息仍可能缺少构图、镜头、光线、材质、空间关系、完成质感和常见缺陷约束。

## 决策

`image_generate` Schema 要求当前对话模型在调用已配置的生图模型前，把用户需求优化为一条连贯、可直接生成的英文 prompt。优化过程保留用户明确指定的主体、数量、可见文字、宽高比、风格、排除项和参考图约束，只增加与当前任务相关的视觉细节。该过程发生在现有对话模型轮次内；Harness 不会在后台额外发起第二次模型请求，也不会改变 Session 已选择的对话模型。

Oasisfish 内置从 YouMind OpenLab revision `6ef324c0aaf3bae6605e21be08f510a7a3fa0cfb` 适配的离线 `ai-image-prompts` Skill。该 Skill 为游戏资产、UI 图片、mockup、海报、产品、肖像、插画、信息图和参考图编辑提供简洁的视觉配方，其来源记录和 MIT 许可证随安装包提供。内置版本不会自更新、下载示例、联系上游服务，也不会在模型回复中附加推广署名。

专用 `game-image` 和 `game-ui` preset 会加载该 Skill，并在生图前通过显式的本地 `skill_search` 检索配方。标准 preset 会在目录中看到该 Skill，在桌面本地提供方可用时拥有相同的检索工具，并从 `image_generate` Schema 获得提示词优化要求。所有路径最终都调用设置中选择的一个默认生图提供方。

## 验证

包测试断言生成的工具 Schema 包含提示词优化要求。preset 组装测试断言专用生图工作流暴露 `skill_search` 并携带优化指令。桌面资源和 staging 清单测试要求 Skill、视觉配方、来源记录与许可证齐全。无密钥 assembled snapshot 会加载真实的内置 Skill 并检索游戏物品视觉配方，不调用对话或生图提供方。

## 考虑过的替代方案

**额外发起一次专门改写提示词的 GPT 请求。** 不采用，因为当前对话模型可以在现有轮次内生成工具参数，额外请求只会增加隐藏延迟、费用、失败处理和另一项模型可见操作。

**替换已配置的生图提供方或增加提供方路由。** 不采用，因为提示词细节和渲染能力是两个独立问题。本次改动改善发送给已选模型的请求，不会假装增加模型多样性或提供方原生功能。

**原样内置上游 Skill。** 不采用，因为运行时更新、示例下载和回复推广不适合自包含桌面工作流。固定 revision 的离线适配保留有用的视觉指导及其许可证，同时移除外部副作用。

**硬编码一套通用提示词模板。** 不采用，因为图标、肖像、UI 背景、产品图和参考图编辑需要不同的构图与缺陷控制。本地配方允许对话模型选择相容的细节，而不是给每条 prompt 堆叠相同的形容词。

## 后果

- 简短生图需求会以信息更充分、针对任务的英文 prompt 进入已配置的生图模型。
- 产品仍只有一个已选择的默认生图模型；提示词优化不会补齐提供方不支持的功能，也不保证渲染质量。
- 专用生图工作流会在生成前执行本地检索，实际对话与生图请求继续使用原有凭据和网络要求。
- 用户要求出现在图片中的文字保持原语言，即使外围生图 prompt 使用英文。
