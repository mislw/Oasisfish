# Agent Note: 设置页中的模型与中转站管理

Status: implemented

[English](2026-08-26-model-relay-management.md) | 中文

## Problem

DeepSeek Harness 已能从 Models 页面声明和编辑提供方 profile，但选择共享默认值仍依赖另一个界面，草稿网关也无法在保存 profile 之前证明其 URL、协议、凭据与模型能够共同工作。配置 OpenAI 兼容中转站的用户需要一个位置，明确区分提供方配置、未来会话的默认值，以及既有 Session 已记录的路由。

## Decision

既有设置导航打开一个由 `dsh-client-ui-settings-models` 所有的“模型与中转站”页面。页面联接提供方目录、模型目录、共享默认值、脱敏后的提供方 settings 与不含值的凭据状态。提供方 profile 继续留在适配器所有的 `llm-pi-ai` namespace 中，凭据值继续以只写方式存入 `ctx.credentials`；页面不引入第二份配置文件或仅桌面端使用的事实来源。这是对[提供方声明决策](../architecture/2026-08-04-declaring-a-provider-from-the-models-page.zh.md)的扩展，而不是替换。

共享默认值是经 `llm.defaultModel` 与 `llm.selectDefaultModel` 选择的显式提供方/模型组合。选择会在持久化前解析所请求的路由，已配置但不可用的默认值保持不可用，不会静默回退。该值只供应尚无已记录路由的 Session。既有 Session 继续从 `request/header` 推导路由，并通过[会话模型选择器](2026-07-24-web-session-model-selector.zh.md)进行会话级变更。共享默认所属的提供方在选择其他默认值之前，无法通过按钮或命令删除。

草稿连接测试由 Host 与适配器家族所有。`llm.testProvider` 接受表单中尚未保存的端点、协议、可选凭据与模型，再让已注册的提供方 probe 发送一次最小请求。结果包含成功样本，或带耗时的端点、鉴权、协议、模型、响应分类失败；提供方响应正文与凭据绝不返回客户端。探测不写 settings、不改变默认值，也不追加 Session 事件。由于该方法接受调用方选择的 URL 与草稿凭据，浏览器载体只允许回环地址的同源请求调用它。

切换完全由用户手动执行。页面不轮换提供方、不做流量均衡、不把一个 turn 失败后改投其他路由，也不会在默认值改变时修改既有 Session。因此，提供方/模型变更仍是显式配置决策，其首次模型可见使用可从 Session 日志重建。

## Verification

LLM registry 与 pi-ai 测试固定 probe 注册、请求分类、中止处理、键入密钥优先级，以及不含机密的失败。ApiProxy 载体测试固定精确 schema、默认值解析、回环拒绝与 signal 传递。客户端状态与组件测试固定联接快照、默认提供方删除保护、安全摘要、未保存草稿探测、响应式控件与双语文案。无密钥浏览器场景通过本地 OpenAI 兼容 relay 执行模型发现、拒绝与接受凭据、连接测试、提供方创建、默认选择、刷新持久化，并保护已有日志的 Session 路由。Windows 发布验收会构建实际交付的 Host 与 Web 产物、打包并安装 Electron 应用，在重启后操作该页面，并确认窗口关闭时 Harness 子进程一同退出。

## Alternatives considered

**构建独立桌面中转站管理器。**拒绝，因为它会在插件配置系统之外重复提供方所有权、凭据存储、验证与失效通知。桌面应用交付的是同一套 Web 组合，因此既有设置页是浏览器与打包应用共用的界面。

**让默认选择切换当前 Session。**拒绝，因为默认值是创建时策略，而既有 Session 可能已有已记录路由与模型可见历史。会话选择器继续作为该 Session 的显式控件。

**直接从浏览器测试端点。**拒绝，因为浏览器 CORS 与代理策略并不等于提供方协议，浏览器将不得不拥有凭据处理，而且适配器的请求构造与错误分类会在 UI 代码中重复。

**加入提供方轮换或自动故障转移。**拒绝，因为把失败 turn 改投其他路由会在没有显式已记录选择决策的情况下改变成本、能力、缓存行为与模型输出。若未来引入轮换，它需要独立设计持久化策略与请求级可观测性。

## Consequences

打包后的 Windows 安装与普通 Web 应用公开同一条单按钮路径，用于提供方 profile、中转站测试、模型发现与未来 Session 默认值。页面可以在不持久化密钥的情况下验证未保存网关，而一次成功测试可能消耗少量提供方额度。既有 Session 保持稳定，无效默认值会显式失败，删除当前默认值需要先明确选择替代项。首个版本提升便利性，但不增加自动路由策略或新的配置所有者。
