# Agent Note: 自定义提供方的图片输入默认值

Status: implemented

[English](2026-09-11-custom-provider-image-input-default.md) | 中文

## Problem

自定义提供方表单只记录模型 id，不记录输入模态。pi-ai 适配器会按约定把未声明路由解析到保守的 `[text]` 回退值，因此支持图片的中转模型虽然可以选择，却会在发送前拒绝图片附件。要启用这项能力只能手工编辑 `settings.yaml`，而配置页在创建位置既不公开该字段，也不解释它。

## Decision

自定义提供方表单默认开启**支持图片输入**，并向新 profile 写入 `defaultInput: [text, image]`。关闭该选项则写入 `[text]`。pi-ai 提供方编辑器也为既有路由公开同一选项，并通过 settings 路径 op API 持久化任一取值。

适配器自身的回退值仍为 `[text]`。因此手写 profile 和未经过此配置页的部署继续采用保守行为，而产品创建流程会把常见的多模态中转选择变成显式且可撤销的配置。

## Alternatives considered

**把适配器全局默认值改为 `[text, image]`。** 这会把图片能力授予每条手写或程序化路由，包括从未经过产品表单的纯文本端点。附件接纳后才发生的提供方失败，比发送前拒绝更难恢复。

**根据模型 id 推断图片能力。** 中转模型名称由提供方所有，可能是别名、前缀或私有版本。名称匹配会在两个方向上静默误判，也无法为纯文本路由提供显式退出选项。

## Consequences

新建自定义提供方无需手工修改 YAML 即可接受图片附件，纯文本路由则能在创建前关闭该能力。既有 profile 会保持其已存含义，直到用户修改该选项。单元覆盖固定两种取值，Web 配置场景固定默认控件、持久化 YAML 与重新打开的编辑器。
