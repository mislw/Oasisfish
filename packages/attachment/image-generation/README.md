# @deepseek-ai/dsh-image-generation

English | [中文](README.zh.md)

Host-owned generated-image capability for auxiliary OpenAI-compatible provider routes. The `image-generation` settings namespace stores a primary route and an optional fallback route. A request may launch several independent candidates; each candidate tries the primary route, then the fallback after a non-cancellation failure. Successful candidates are persisted through `ctx.attachments` in request order, while exhausted candidates do not discard the others. An Images API route accepts Base64 or HTTP(S) URL responses. A `chat/completions` route requests text and image modalities and accepts one Markdown-embedded image Data URL per candidate.

Failed JSON responses may contribute a short `error.message` or top-level `message` to the tool error. The service normalizes whitespace, truncates the detail, and redacts the resolved API key; non-JSON and unrecognized response bodies remain hidden.

## Config

| Key | Default | Meaning |
|---|---|---|
| `provider` | empty | Initial provider route; the Models settings page normally writes it. |
| `model` | empty | Initial image model id. |
| `endpointPath` | `images/generations` | Relative path appended below the provider Base URL. Use `chat/completions` for models that return a Markdown image Data URL from an OpenAI-compatible chat response. |
| `editEndpointPath` | `images/edits` | Relative path used when a request includes reference images. |
| `fallbackProvider` | empty | Optional provider route tried after a non-cancellation failure from the primary route. |
| `fallbackModel` | empty | Image model id paired with `fallbackProvider`. |
| `fallbackEndpointPath` | `images/generations` | Relative text-generation path for the fallback route. |
| `fallbackEditEndpointPath` | `images/edits` | Relative reference-edit path for the fallback route. |
| `maxResponseBytes` | `25000000` | Maximum Images API JSON body or downloaded image body. |

## Model Experience

### Tool result attachment

#### What the model sees

This Host service contributes no prompt or schema of its own. Through the `image_generate` Consumer, the model-visible result contains `已生成 N 个方案，请选择。` followed by every successful image block. Generated bytes stay outside the session log; each block carries a durable attachment reference.

#### Token effect

The fixed text result is retained until compaction. The image contributes the selected model adapter's image-token cost when later requests include it.

#### KV Cache effect

Append-only. The new tool result follows the reusable request prefix; later provider image projection may change only the affected suffix.

## Known Limitations and Deferred Work

- Reference-image requests require an Images API route and send every supplied image to `POST /images/edits` without a mask; chat-completions routes do not accept references, size, or quality controls. Candidate variations append to one shared prompt; provider-specific mask, background, and output-format controls are not exposed.
- A selected route must have an explicit `baseURL` in `llm-pi-ai`; catalog-only routes whose endpoint is implicit are not resolved by this provider.
