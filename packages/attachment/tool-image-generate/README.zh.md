# @deepseek-ai/dsh-tool-image-generate

[English](README.md) | 中文

面向模型的 `image_generate` Consumer，调用 `ctx.imageGeneration`。其 Schema 要求当前对话模型在调用前，把简短需求优化为一个细节充分、可直接生图的英文共同 prompt，并提供四条简短候选差异。工具自动复用最近一条直接用户消息中的图片作为编辑参考，发起四个独立候选，保留部分成功结果，并返回“已生成 N 个方案，请选择。”与可持久读取的图片附件。调用成功后会立即结束本轮，因此不会再次调用对话模型生成收尾文字。

## 配置

| 键 | 含义 |
|---|---|
| `timeoutMs` | 由共享超时策略执行的协作式工具调用时限。 |

## 模型体验

### 工具 Schema

#### 模型看到的内容

模型会看到生成的 [`image_generate` Schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-image-generate)，并被要求在用户提出生成、绘制、渲染或编辑图片时调用。同一个对话模型轮次会在调用前把简短描述扩展成连贯的英文 prompt，按任务需要补充主体、环境、构图、镜头、光线、材质、色彩、空间关系、完成质感和负面约束，同时保留用户明确指定的文字与参考图要求；它还会提供四条 `variation_prompts`，在不改变共同需求的前提下调整构图、材质、光线、镜头或图形结构。这个过程不会在后台额外发起第二次对话模型请求。其他参数包括可选的提供方支持 `size` 和 `quality`，以及 `use_reference_images`。工具默认使用最近一条包含图片的直接用户消息；只有当目标图片必须与这些输入无关时，模型才把 `use_reference_images` 设为 `false`。参考图请求默认使用高输出质量。

#### Token 影响

该工具可见时，每次请求都会产生固定的 Schema 成本。

#### KV Cache 影响

工具定义与可见性不变时前缀稳定。预设变化、插件生命周期或作用域限制可能从该 Schema 起影响复用。

### 生成图片结果

#### 模型看到的内容

结果包含“已生成 N 个方案，请选择。”和全部成功图片附件。工具结果记录后立即结束本轮；当前对话模型选择保持不变，也不会再发起收尾模型请求。

#### Token 影响

保留的结果文本固定且很短。后续请求的适配器包含该耐久图片块时，可能产生图片 token。

#### KV Cache 影响

仅追加；结果位于可复用请求前缀之后，不会使此前条目失效。

## 已知限制与后续工作

- 每次调用请求四个候选，并允许部分成功。模型可以选择输出质量和是否复用参考图，但提供方专属的蒙版、背景和输出格式暂不进入工具 Schema。
- 提示词优化会改善发送给已配置生图模型的指令；备用行为取决于 Host 配置的可选路由，不会扩展任一模型原生的渲染能力。
